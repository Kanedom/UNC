# 🏥 Union Health Clinic

**Private Patient Management System — Dr. Kenneth Maima**

A fully offline-capable Progressive Web App (PWA) for managing patients, appointments, medical records, and financial records at Union Health Clinic.

---

## ✨ Features

| Module | What it does |
|---|---|
| **Dashboard** | Daily overview — today's appointments, patient count, revenue summary |
| **Patients** | Add, view, edit, delete patient profiles with full medical info |
| **Appointments** | Schedule, filter, and mark appointments; today badge on nav |
| **Medical Records** | Log diagnoses, prescriptions, vitals, follow-up dates |
| **Finance** | Track income & expenses in K (Kina), paid/pending status, net balance |

---

## 📱 Install on Android

1. Open the app URL in **Chrome**
2. Tap the menu (⋮) → **"Add to Home Screen"**
3. Or tap **"Install"** on the banner that appears
4. Opens like a native app — no browser bar

## 💻 Install on PC (Windows / Mac)

1. Open the app URL in **Chrome** or **Edge**
2. Click the **install icon** (⊕) in the address bar
3. Or go to browser menu → **"Install Union Health Clinic"**
4. Launches as a standalone desktop app

## 🌐 Deploy on GitHub Pages (Step by Step)

### Step 1 — Create a GitHub account
Go to [github.com](https://github.com) and sign up (free).

### Step 2 — Create a new repository
- Click **"New"** (green button)
- Name it: `union-health-clinic`
- Set to **Public**
- Click **"Create repository"**

### Step 3 — Upload the files
- Click **"uploading an existing file"**
- Drag and drop ALL files from this folder:
  - `index.html`
  - `manifest.json`
  - `sw.js`
  - `icons/` (the whole folder)
- Click **"Commit changes"**

### Step 4 — Enable GitHub Pages
- Go to your repo → **Settings** tab
- Scroll to **Pages** (left sidebar)
- Under **Source**, select **"Deploy from a branch"**
- Branch: `main` / Folder: `/ (root)`
- Click **Save**

### Step 5 — Get your URL
After ~2 minutes, your app will be live at:
```
https://YOUR-USERNAME.github.io/union-health-clinic/
```

## 🔒 Privacy & Data

- **All data is stored locally** on the device using browser localStorage
- No data is sent to any server
- No internet required after first load (works fully offline)
- Each device maintains its own data
